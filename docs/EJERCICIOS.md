# Enunciados de la práctica

Este archivo es la fuente de requisitos para los agentes. La interfaz debe estar en español y cada ejercicio debe resolverse de forma independiente.

## Ejercicio 1: Factorial

Realizar un programa que calcule el factorial de un número mayor o igual que cero mediante una función o método recursivo.

## Ejercicio 2: Fibonacci

Realizar un programa que genere la serie de Fibonacci utilizando recursividad.

## Ejercicio 3: Máximo Común Divisor

Realizar un programa que calcule el MCD (Máximo Común Divisor) de dos números enteros. Debido al tema de la práctica, debe emplearse una solución recursiva.

## Ejercicio 4: Cambio de monedas

Crear una aplicación en C# que indique cuántas monedas de cada denominación deben devolverse en una operación comercial, utilizando el mínimo número total de piezas.

Denominaciones disponibles: 100, 50, 20, 10, 5 y 1 peso; 50, 20 y 1 centavo.

El usuario proporciona el importe de la compra y la cantidad pagada. Por ejemplo, si la compra es de 73.26 pesos y se pagan 100 pesos, el cambio es 26.74 pesos: una moneda de 20, una de 5, una de 1, una de 50 centavos, una de 20 centavos y cuatro de 1 centavo. Debido al tema de la práctica, el procedimiento principal debe demostrar recursividad.

## Ejercicio 5: Torres de Hanói

Leer el número de discos indicado por el usuario y describir, mediante recursividad, los movimientos necesarios para trasladar todos los discos de la torre de origen a la torre de destino.

Reglas:

1. Solo se puede mover un disco cada vez.
2. Un disco mayor no puede descansar sobre uno más pequeño.
3. Solo se puede desplazar el disco superior de cada torre.

## Requisito visual común

Dentro del apartado principal de cada ejercicio debe existir una sección visible titulada `¿Cómo funciona?`. Debe explicar las entradas, el caso base, el paso recursivo, el resultado y un ejemplo breve de ejecución.
